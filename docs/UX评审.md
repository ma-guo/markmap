## 1. 现状交互审计

### 1.1 导航与信息架构

```
MainActivity → 组列表 → 路线列表 → 点列表 → 点编辑
                    ↘ 路线地图 / 点地图
组列表右上角：列车运行图、余票查询
```

问题：**「组 / 线 / 点」是数据模型术语，不是用户语言**；「行程 / 路段 / 地点」更符合旅行记录场景。

### 1.2 问题清单

| 级别 | 问题 | 现状 | 影响 |
| --- | --- | --- | --- |
| P0 | **组无法删除** | `GroupEditActivity` 未加载 `menu_group_edit`，菜单文件存在但未使用 | 用户无法删除行程 |
| P0 | **删除无回收站** | DAO 已有软删除与 `getDeletedXxx`，UI 无入口 | 误删不可恢复 |
| P0 | **核心「合并」无入口** | 无合并页面/按钮 | 产品核心价值不可达 |
| P1 | 长按编辑不可发现 | 组/线长按进入编辑，无任何提示；点却单击即编辑 | 操作不一致、学习成本高 |
| P1 | 空状态文案错误 | 路线列表写「点击右上角菜单添加」，实际为右下 FAB | 引导错误 |
| P1 | **排序值输入框外露** | 组/线/点编辑页均有「排序值」数字输入 | 暴露内部实现，用户困惑 |
| P1 | 地图页操作拥挤 | 右侧 3 个悬浮按钮 + 长按上锁 | 主次不清、隐藏交互 |
| P1 | 保存入口不一致 | 编辑页底部按钮；设置页顶部菜单 | 预期不一致 |
| P1 | 全屏 Loading 闪烁 | 本地 Room 查询也显示居中 ProgressBar | 视觉跳动 |
| P2 | 无搜索/筛选 | 行程多时只能滚动 | 效率低 |
| P2 | 无未保存提示 | 返回即丢失输入 | 易出错 |
| P2 | 文案生硬 | 「暂无数据\n点击右下角添加」 | 缺少温度 |
| P2 | 图标语义模糊 | 路线地图「设置」用罗盘图标，实为显示设置 | 误解 |

### 1.3 符合中国用户习惯的要点

1. **点击进入详情，编辑用显式入口或右滑**，不依赖长按。
2. **删除必须可撤销或二次确认**；列表左滑删除是共识。
3. **主操作固定在底部或右下**，次操作收进「⋯」。
4. **中文口语化文案**，避免工程术语。
5. **表单少手输**：日期用选择器，交通方式用 chips，排序用拖拽。
6. **空状态给行动指引**，不是一行灰字。
7. **加载用骨架/轻提示**，避免全屏转圈。

## 2. 三套交互方案（迭代版本）

### 方案 A：克制增强版（改动最小）

- 保留「组 → 线 → 点」三级列表结构。
- 单击进入下一级；右滑编辑；左滑删除（Snackbar 撤销）。
- 顶部：搜索 + 「⋯」（回收站/设置/列车/余票）。
- 隐藏排序值，改为拖拽排序。
- 地图页：底部抽屉替代多个悬浮按钮。
- **优点**：改动小、上线快；**缺点**：「行程」感弱，合并入口仍偏工具化。

### 方案 B：行程中心版（推荐，已出图）

- 首页 = **行程卡片列表**（缩略轨迹、日期、里程、交通方式）。
- 行程详情 = 地图头图 + 统计 + **路段卡片** + 底部「合并查看 / 分享」。
- 记录页 = 全屏地图 + 底部抽屉 + 单一主按钮。
- 合并 = 独立编辑器：勾选 → 拖拽 → 切方向 → 预览。
- 分享 = 行程卡片预览 + 模板 + 保存/分享。
- **优点**：贴合「记录旅行轨迹」定位，天然承载 M2 徽章/足迹；**缺点**：UI 工作量中等。

### 方案 C：地图优先版

- 首页 = 全屏地图，底部行程抽屉。
- 点击轨迹进入行程详情底部面板。
- **优点**：沉浸、分享视觉强；**缺点**：多行程管理弱，学习成本高，不适合作为首版。

### 结论

采用 **方案 B**（吸收 A 的列表手势：左滑删除、右滑编辑、Snackbar 撤销）。本轮线框图与高保真均按 B 输出。

## 3. 方案 B 关键交互规范

### 3.1 行程列表
- 顶部大标题 + 副标题 + 搜索。
- 卡片点击 → 行程详情；右滑 → 编辑；左滑 → 删除（可撤销）。
- 右下 FAB「＋」→ 新建行程（底部弹层：名称 + 日期 + 交通方式）。
- 右上「⋯」：回收站、设置、列车运行图、余票查询。
- 空状态：插画 + 「记录第一段旅程」主按钮。

### 3.2 行程详情
- 顶部地图预览（自动适配所有路段）。
- 统计三项：里程 / 时长 / 城市数。
- 路段卡片：交通方式色条 + 图标 + 起止 + 时间 + 里程；点击进路段详情。
- 底部固定：分享（次）+ 合并查看（主）。
- 长按/右滑路段 → 编辑；左滑 → 删除。

### 3.3 记录地图
- 底部抽屉：地址、精度、距上一点、速度、已记录。
- 中央大按钮：开始/暂停；左右文字「暂停 / 结束」。
- 次级操作：标记、路线、后台。
- 记录状态胶囊：红点 + 时长 + 里程，常驻顶部。
- 退出记录必须二次确认。

### 3.4 合并轨迹
- 顶部地图预览：各段不同颜色，连接线陶土色虚线。
- 列表：拖动排序、勾选参与、⇄ 切方向、全选。
- 开关：显示连接线。
- 底部：取消 + 生成合并轨迹。
- **无任何自动阈值**（与 PRD 5.3 一致）。

### 3.5 分享
- 预览卡：地图 + 标题 + 日期 + 统计 + 印章。
- 模板：山水 / 极简 / 航空。
- 底部：保存图片 / 分享。
- 生成中给轻量进度，不阻塞。

### 3.6 通用反馈
- 删除：Snackbar「已删除 · 撤销」，5 秒。
- 保存：轻 Toast 或顶部提示，不打断。
- 加载：骨架屏；本地查询 <100ms 不显示 loading。
- 返回：有未保存修改时弹「放弃修改？」。
- 触控：所有可点区域 ≥ 48dp。

## 4. 文案建议（术语替换）

| 现在 | 建议 |
| --- | --- |
| 组 / 组列表 | 行程 / 我的行程 |
| 线 / 路线列表 | 路段 / 行程路段 |
| 点 / 点列表 | 地点 / 轨迹点 |
| 排序值 | 移除（改为拖拽排序） |
| 暂无数据 | 还没有行程，记录第一段旅程吧 |
| 标记该位置 | 标记此处 |
| 自动保存已开启 | 后台记录已开启 |

## 5. 已确认

1. 采用 **方案 B（行程中心版）**。
2. 术语统一为 **行程 / 路段 / 地点**。
3. 删除交互采用 **左滑 + 撤销**（Snackbar）。
4. 底部 Tab 首版加入 **行程 / 足迹 / 我的**（足迹为 M2 内容）。
